# Legacy Vanilla JS & Express Prototype

This folder contains the earlier standalone prototype (Express + SQLite/JSON + Vanilla JS).
The modern production application is split into:
- `/frontend`: Next.js 16 + React 19 Client
- `/backend`: Python FastAPI + Scikit-learn + XGBoost + RL System

If you wish to run this legacy prototype standalone:
```bash
npm install
node server.js
```
Open `http://localhost:5000` in your browser.
